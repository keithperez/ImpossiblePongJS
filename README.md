# Assignment 03 - Impossible Pong
Play it on my [itch.io!](https://keithperez.itch.io/assignment03-game)

## Instructions
Super simple game where you just need to survive against the opponent's paddle for as long as you can.

To start the game you click, and to move the paddle you move your mouse OR use the arrow keys to move up and down. 

NOTE: If you do use the arrow keys, then the mouse will be disabled for the rest of that round to prevent your paddle from moving to where the mouse was. Once you reset by clicking, mouse controls work again.

I did update it after I turned it in, but it was to add support for arrow keys and fix a bug where the ball would trap itself on the ceiling and floor of the viewport and stay there no matter what.
